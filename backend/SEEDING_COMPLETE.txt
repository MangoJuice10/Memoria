 Usage:
=============================================================================

Full Seed (Clean + Fill Everything):
  cd backend
  npm run seed

Clean Only (Preserves Users & Educational Resources):
  npm run seed:clean

Partial Seed:
  npm run seed:users          # Just users
  npm run seed:tags           # Just tags
  npm run seed:decks          # Just decks + flashcards
  npm run seed:reviews        # Just review history
  npm run seed:feedbacks      # Just feedbacks
